# 第一次使用：跟着做一遍

这份教程给第一次使用 FolioHook 的人。**你来操作，不需要写代码；每做完一步，看一眼“成功标志”再继续。**

这次不假定你已经配好 MCP 或 Key：从准备软件开始，教你亲手添加本机连接、创建网页连接，再各查一次资料。已经完成的步骤可以跳过，但不要为了练习先删除旧配置。

本教程对应当前主工作区已纳入的正式 UI 与近期修复，但还不是正式安装包。不要导入私人文献，也不要删除原有的库。

## 这次要走的完整路线

启动应用 → 建库与导入 → 普通搜索与版本 → 可选增强设置 → 第一次配置本机 MCP → 第一次配置网页 MCP → 各自测试 → 日常启停。

普通搜索不需要 API Key。增强搜索会用到付费 API，下面会在按钮前提醒你。**已经保存的 Key、已经建好的连接，不要重做。**

### 快速找到你要做的部分

- 软件还没准备好：从下面第 0 步开始。
- 只想学习本机连接：完成第 1～4 步后，跳到[第 8 步](#第-8-步第一次配置本机-mcp再让-codex-查询)。暂时不用准备 Key。
- 想学习 ChatGPT 网页连接：完成第 1～4 步后，跳到[第 9 步](#第-9-步第一次配置-chatgpt-网页-mcp)。网页普通搜索只需 OpenAI Tunnel 运行 Key。
- 还想按意思增强搜索：再完成第 5～7 步，需要阿里云 Key。

### 先分清三个页面和两个 Key

| 打开的地方 | 在这里做什么 |
|---|---|
| FolioHook 本机管理页 | 建库、导入、保存 Key、复制本地连接配置、启动 Tunnel |
| 本机 Codex 的设置 | 添加并启用本机 MCP，让这台电脑上的 AI 能读库 |
| ChatGPT 网页及 OpenAI Platform | Platform 管理 Tunnel 和运行 Key；ChatGPT 网页添加连接并提问 |

**阿里云 Key**只填 FolioHook「全局设置」；**OpenAI Tunnel 运行 Key**只填 FolioHook「连接 AI 应用」的真实 Tunnel 区。本机 MCP 配置里不用填这两个 Key。Key 相当于有权限的密码，不是库名，也不是网址。

## 第 0 步：准备软件，打开 FolioHook

### 0.1 先看当前版本能做到哪里

当前是 M 系列 Mac 的源码开发版，不是下载后拖进“应用程序”就能用的正式 App；Windows 教程要等对应安装包完成。当前主工作区源码已包含本文对应的界面；仍应使用维护者确认的完整版本，不要只拿一个启动脚本或假定已有安装包。

如果维护者已给你完整的教程对应项目目录，按下面启动。如果还没有，先取得明确版本的完整目录，**不要只下载一个 `.command` 文件**。这属于尚未完成的发行交付步骤，不是你不会操作。

1. 在 Mac 左上角苹果菜单→「关于本机」看“芯片”，应为 Apple M 系列。
2. 没装合适 Python 时，打开 [Python 官方 Mac 下载页](https://www.python.org/downloads/macos/)，下载 Python 3.11 或更新版本的 macOS 安装包，双击按提示安装。系统密码／许可由你自己确认。已经装好且启动器检查通过就不用再装。
3. 在 Finder 打开完整项目，双击 **启动文献证据管理页.command**。
4. 首次会检查环境、联网安装运行依赖；等待终端给出管理页地址并打开浏览器。遇到系统安全拦截先停下核对，不关闭系统保护。
5. 保持这个终端开着。默认地址是 `http://127.0.0.1:8765/`，测试环境可能不同，以实际显示为准。

**成功标志：** 页面有文献库选择、文档、搜索、版本历史、全局设置、连接 AI 应用等入口。若只出现报错，先处理报错，不要继续配置 Key。

### 0.2 要不要清空已有状态？

**不要。** 学习建库只需新增练习库；要练“第一次配 Key 和连接”，应另外准备一个空的隔离实例，保留现在已成功的实例。

隔离实例需要独立资料位置、空的应用设置、自己的本机 MCP 名称。两套网页连接不能同时争用同一个 Tunnel ID。仅换一个浏览器标签、端口或 Git 工作树，不代表完成隔离。

第一次使用的新电脑直接走默认实例；已有工作环境时，先由管理任务确认隔离实例的名字、地址与影响范围，再创建。**本文不要求你删除文献、钥匙串条目、旧 Tunnel 或已有 MCP。** 独立实例练习也不等于“干净新 Mac 安装验收”。

## 第 1 步：建一个自己的练习库

1. 左侧点「＋ 新建」。
2. 名称填：**我的上手练习**。
3. 简介填：**只放练习文件，不是真实研究资料**。
4. 点「创建文献库」。

**成功标志：** 页面标题显示「我的上手练习」。如果已有同名库，先停一下核对，不要反复新建。

## 第 2 步：导入第一份文件

已经提供两份纯虚构练习文件，不用自己制作：

- [蓝桥电池.md](练习资料/蓝桥电池.md)：第一轮只导入这一份。
- [蓝桥补充.md](练习资料/蓝桥补充.md)：留到第 4 步再导入。

它们位于完整项目文件夹里的 **docs → 练习资料**。

1. 点「＋ 导入文档」。
2. 选择「从空白建立」。
3. 在文件选择窗口找到上述文件夹，选择 **蓝桥电池.md**。
4. 核对目标库是「我的上手练习」，只选择了一份文件。
5. 点「明确导入并建立版本」，等待成功提示。

**成功标志：** 文档列表出现「蓝桥电池练习」，共有 1 篇文档。

“版本”就是这次保存下来的整套资料。第一次导入成功，这个版本会自动成为当前版本。

## 第 3 步：搜一次，再亲眼核对答案

1. 左侧点「搜索」。
2. 选择 **本地 BM25**。它就是普通关键词搜索，不调用付费模型。
3. 输入 **bluebridge317**，提交搜索。
4. 点开结果，查看内容与来源行号。
5. 打开本教程上方的「蓝桥电池.md」，对照原文。

**成功标志：** 摘录中出现 **31 kWh** 和 **7 秒**，来源是「蓝桥电池.md」。

看到“文本片段：几段”不用担心：程序把一篇文档拆成几段，方便检索。它不是文件数量。

## 第 4 步：添加第二份文件，理解版本

1. 点「＋ 导入文档」。
2. 这次选择 **「基于当前浏览版本继续」**，这样才会保留第一份文件。
3. 选择 **蓝桥补充.md**，核对后点「明确导入并建立版本」。
4. 去「版本历史」，找到新版本，点「浏览文档」。
5. 确认新版本有 2 篇，再去「版本历史」，把新版本「设为当前版本」。

**成功标志：** 新版本有 2 篇，旧版本仍有 1 篇；新版本带有“当前”标记。

只记住两句话：

- **浏览版本**：我现在在看哪一套资料。
- **设为当前版本**：我希望 AI 接下来使用哪一套资料。

之后回到新版本搜索 **bluebridge842**，应找到 **18%**。如果 AI 还在回答旧资料，先检查有没有把新版本设为当前。

## 第 5 步：设置增强搜索

增强搜索更擅长按意思找资料。这里需要一份**阿里云 API Key**，不是 OpenAI Key。

如果只想先把 MCP 连接跑通，可以跳到第 8 步，之后再回来做增强。

### 5.1 第一次获取阿里云 Key

1. 打开[百炼北京地域 API Key 页面](https://bailian.console.aliyun.com/cn-beijing/model/settings/api-key)，登录自己的阿里云账号。
2. 首次使用按页面提示开通服务；遇到实名认证或服务协议，由你自己阅读并决定。先了解模型按量计费，不默认等于已有套餐免费。
3. 确认地域是 **华北2（北京）**。不要复制新加坡等其他地域的 Key。
4. 点「创建 API Key」。个人练习选择自己的归属账号与业务空间；如果页面提供自定义模型权限，允许 FolioHook 当前三个角色所用模型，不要随意授予无关管理权限。页面无权限时找账号管理员，不借用别人的 Key。
5. 创建成功后自己复制完整 Key；不要发聊天或截图，也不要复制成阿里云 AccessKey ID／Secret。

这里使用标准百炼模型 API Key；其他套餐或 Token Plan 的专用 Key 不应直接混用。官方页面变动时，以[阿里云获取 Key 说明](https://help.aliyun.com/zh/model-studio/get-api-key)为准；本项目不用其中的“保存到环境变量”方法。

### 5.2 填回 FolioHook

1. 左侧点「全局设置」。
2. 将刚复制的 Key 粘贴到「阿里云 API Key」，点「保存到本机钥匙串」。如果已配置且有效，跳过替换。
3. 点「使用推荐配置」。不用自己研究三个模型的名字。
4. 勾选「启用 AI 增强搜索」。

**成功标志：** 页面显示 Key 已配置、增强已启用。

这一步只是保存设置，**还没有给文件准备向量**。旁边「检查三个模型连接」会发真实测试请求、可能收费，本次不必额外点击。

## 第 6 步：给新版本准备向量

“准备向量”可以理解成：先把资料加工成适合按意思搜索的数据。

1. 去「版本历史」，找到刚才有 2 篇文件的当前版本。
2. 点「准备向量」，再点「查看发送量」。
3. 看清它准备发送多少文本、调用多少次。**目前还没发送，也没产生这次模型调用费用。**
4. 如果你同意把这些虚构练习文本交给服务商处理并接受费用，再点 **「明确发送并构建向量」**。
5. 等待完成，看这个版本的向量是否准备好。

**成功标志：** 构建成功、版本向量可用。若失败，停下来把不含 Key 的错误提示告诉维护者，不要一直重试。

以后新增文档，可以复用同一库中匹配的旧向量，不一定全做一遍；每次先看发送量就好。换向量模型后可能要重新准备。

## 第 7 步：在应用里做一次增强搜索

**这一步会调用付费模型。**

1. 左侧点「搜索」，确认仍是练习库的新版本。
2. 选择「AI 增强搜索」。
3. 输入：**蓝桥练习中，储能容量是多少，调度延迟是多少秒？**
4. 提交一次，等结果。

**成功标志：** 结果能找到 **31 kWh、7 秒**及对应出处，并显示实际调用情况。

切换搜索模式不会自动发送问题；不要把上一次的结果当成这一次的结果。

## 第 8 步：第一次配置本机 MCP，再让 Codex 查询

这一步只连**本机 Codex**，不是 ChatGPT 网页。不需要 OpenAI Key，不需要 Tunnel，也不要把浏览器里的管理页地址填成 MCP 服务器 URL。

### 8.1 先检查 FolioHook 的本机入口

1. 在你准备连接的 FolioHook 页面点「连接 AI 应用」。
2. 找到「本机 MCP · 八个只读工具」，点「运行本地离线 STDIO 自检」。
3. 等待“自检通过：8 个只读工具”。如果复制按钮灰色或自检失败，先停在这里处理入口问题。

**成功标志：** 自检通过、能复制配置。但此时还没有替你添加到 Codex。

### 8.2 亲手添加连接：默认用 Codex 设置界面

**推荐走这一条：不用终端，也不用手改配置文件。**

1. 在 FolioHook 点「复制 TOML（不写配置）」，查看当前实例生成的连接设置。这几行只是填表参考，不会自动添加连接；不要整段粘进“启动命令”。
2. 打开 Codex「设置 → 插件 → MCP」，点右上角「添加 → 添加 MCP 服务器」。不同版本可能直接叫「MCP 服务器」。
3. 先看已有列表：如果已经有同名连接，先核对它是否就是本次要连接的实例，不重复添加或覆盖。
4. 在「连接至自定义 MCP」中，按下表填写。参数要分成**两个输入框**；点「＋ 添加参数」添加第二个。

| 界面里的项目 | 怎么填 |
|---|---|
| 名称 | 当前配置第一行 `[mcp_servers.名称]` 中的名称，不带前面的 `mcp_servers.` 和方括号 |
| 类型 | 选 **STDIO**，不要选“流式 HTTP” |
| 启动命令 | `/bin/zsh` |
| 参数，第一个框 | `-fc` |
| 参数，第二个框 | 当前配置 `args` 中以 `exec` 开头的整项，见下面示例；整项放在同一个框 |
| 环境变量 | 留空，不填 API Key |
| 环境变量传递 | 留空 |

**如何看懂第二个参数？** 例如，默认安装位置生成的配置是：

```toml
[mcp_servers.literature-evidence]
command = "/bin/zsh"
args = ["-fc", "exec \"$HOME/Library/Application Support/literature-evidence-mcp/mcp-server\""]
```

对应的名称填 `literature-evidence`，第二个参数框填下面这一整行：

```text
exec "$HOME/Library/Application Support/literature-evidence-mcp/mcp-server"
```

注意：填表时不带 TOML 的外层双引号、方括号、逗号；示例中的 `\"` 变成普通的 `"`，路径两侧的引号仍要保留。

**上面只是默认安装位置的示例，不是所有实例通用的配置。** 如果你使用独立练习实例，名称通常带 `test-…`，第二个参数是指向该实例的 `exec …/mcp-server`。两项都必须使用当前 FolioHook 页面生成的内容，不照抄上面的默认值，也不照抄另一台电脑的路径。看不懂引号时，先让陪同者把这两项整理成可直接粘贴的值，不凭猜测删字符。

5. 向下滚动，点页面的保存／添加按钮。
6. 回 MCP 列表，确认出现刚才的名称。接着做 **8.3 的实际查询**。

**成功标志：** 列表中出现目标连接。这里只证明配置已保存，还不证明 AI 已经读到了你的库。[官方 MCP 配置说明](https://learn.chatgpt.com/docs/extend/mcp)

以下两种是备选；界面已经添加成功就跳过，不要重复添加。

### 8.3 启用并实际查一次

1. 回 Codex「设置 → 插件 → MCP」（有些版本叫「MCP 服务器」），确认刚才那条连接处于启用状态；不操作其他连接。
2. 如界面提供 Restart／重新启动，重新加载这条连接。仍没出现工具时，先保存工作，再退出并重开客户端。
3. 新开一个测试任务，发送：

> 请只用我刚配置的 FolioHook MCP 实际查询，不要读本地文件或旧聊天。先列库，找到「我的上手练习」，再列出并选择它的当前激活版本。用普通搜索 search_documents，mode="bm25"，搜索 bluebridge842。请告诉我备用裕度，并给出文件名和行号。不要调用付费增强搜索。如果有多个 FolioHook 连接或同名库，先让我确认。

**成功标志：** 展开实际调用，能看到列库、选择版本、搜索；答案是 **18%**，来源为 **蓝桥补充.md**。只有 AI 说“已连接”，不能算成功。

如果提示没有工具，先查连接是否启用／重新加载；如果有工具却没有练习库，先查是不是连到了另一实例。不要马上重新导入或生成 Key。

## 第 9 步：第一次配置 ChatGPT 网页 MCP

网页不会读取你刚才加到本机 Codex 的设置。它需要另一条通道：**Tunnel（隧道）**。

这一节按顺序做：确认能用开发者模式 → 确认连接程序可用 → 创建 Tunnel → 生成运行 Key → 填回应用 → 启动 → 在网页添加连接 → 实际查询。

### 9.1 先确认账号入口

1. 登录你打算使用的 ChatGPT 账号，确认当前是个人还是团队／学校工作区。
2. 打开「设置 → 安全与登录」，寻找「开发者模式」并阅读提示后启用。
3. 没有这个选项或不允许启用时，先核对账户／工作区政策；不要为了继续教程盲目购买订阅。

**成功标志：** 可以进入插件／应用的开发者新增连接入口。[官方 ChatGPT 设置步骤](https://developers.openai.com/plugins/deploy/connect-chatgpt)

### 9.2 安装连接程序（Mac，只需装一次）

`tunnel-client` 是连接 ChatGPT 网页的桥梁；**只用本机 MCP 的话，可以跳过这一节**。当前开发版不会自动安装，但支持识别应用自带程序和 Homebrew 标准位置的安装。Homebrew 可以理解为 Mac 的命令行软件安装工具。

**先看是否已经安装：** 打开 FolioHook「连接 AI 应用」，看真实 Tunnel 区域的「连接程序」。如果显示 **已找到**，直接去 9.3，不要重复安装。这里只检查程序文件，不读取 Secret Key，也不会自动连接。

**显示“未找到”时，按下面做：**

1. 按 `Command + 空格`，搜索「终端」，回车打开。
2. 粘贴下面这一行，按回车。它只检查 Homebrew 是否可用：

   ```bash
   brew --version
   ```

3. 如果出现 `Homebrew` 和版本号，继续第 4 项。如果显示 `command not found`：
   - 打开 [Homebrew 官方网站](https://brew.sh/)，找到 **Install Homebrew**，复制它提供的安装命令到终端，按回车。
   - 安装会联网下载软件，可能需要安装 Apple 命令行工具；按官方提示操作。需要 Mac 登录密码时由你自己输入，终端不显示字符是正常的；不是输入 OpenAI Secret Key。
   - 完成后查看终端的 **Next steps**，按它给出的命令设置 Homebrew。不同电脑命令可能不同，不照抄别人的用户名或路径。
   - 关掉这个终端窗口，再打开一个终端，重新执行 `brew --version`。仍报错就先停下求助，不继续粘贴后面的命令。
4. 复制以下一整行到终端，按回车，等待安装结束：

   ```bash
   brew install openai/tools/tunnel-client
   ```

5. 检查程序能运行：

   ```bash
   tunnel-client --version
   ```

   **成功标志：** 输出版本号，没有报错。不需要在终端输入 Secret Key、Tunnel ID 或执行 `tunnel-client run`。
6. 回 FolioHook 刷新页面，再进「连接 AI 应用」。现在「连接程序」应显示 **已找到**，再继续下一节。

应用优先使用自身目录内的程序，其次识别 Apple Silicon 常见的 `/opt/homebrew/bin/tunnel-client` 或 Intel 常见的 `/usr/local/bin/tunnel-client`。不会复制其他实例的资料、配置或 Secret Key，也不依赖启动应用时的终端 PATH。自定义安装位置不在本教程范围；若版本命令成功但应用仍找不到，先核对是否使用了含此修复的版本，交维护者检查，不要自己搬文件或复制别人的配置。

不要关闭 macOS 安全保护来运行被拦截的下载文件；出现安全拦截请停下核对官方安装方式。安装完成不等于实际连接成功，9.6 和 9.7 还要分别检查启动与网页工具发现。[OpenAI 官方 Tunnel 说明](https://developers.openai.com/api/docs/guides/secure-mcp-tunnels)、[官方客户端安装说明](https://github.com/openai/tunnel-client#install-with-homebrew)。

**以后能否省掉安装步骤？** 计划中的桌面安装包可以考虑内置连接程序，但当前尚未打包。发布前需核对该版本及附带组件的分发许可、保留许可证/声明，完成对应系统的签名、公证与干净环境测试。即使内置，Secret Key 与账号授权仍由每位用户自己配置，不能随包提供。

### 9.3 创建你自己的 Tunnel

1. 打开 [OpenAI Platform 的 Tunnel 设置](https://platform.openai.com/settings/organization/tunnels)，登录自己的账号。
2. 核对页面里的组织是你要使用的组织。个人账号和团队／学校账号别混选。
3. 点新增／创建 Tunnel，名称可填 **FolioHook 上手练习**，说明填“仅用于虚构练习资料”。
4. 按页面要求关联自己的 Platform 组织与目标 ChatGPT 工作区。下拉项只有一串看不懂的 ID 时，先核对身份，不猜选，也不把工作区一律留空当通用步骤。
5. 创建后复制 **Tunnel ID**，保存为普通连接信息。它通常以 `tunnel_` 开头，**不是 Secret Key**。

创建／管理需要 Tunnels **Read + Manage** 权限；运行／选用需要 **Read + Use**。看到权限不足时交给该组织管理员处理，不是重置 FolioHook。[官方权限与关联说明](https://developers.openai.com/api/docs/guides/secure-mcp-tunnels)

**成功标志：** 设置页存在你刚创建的 Tunnel，名称与 ID 对得上。已有同用途资产可复用，不必每次创建；独立环境同时运行时应使用不同 Tunnel ID。

### 9.4 生成 OpenAI API Secret Key

**Secret Key** 就是 OpenAI API 密钥；这里专门用于运行 Tunnel。它不是 ChatGPT 登录密码，也不是上一节的 Tunnel ID。应用界面目前把它叫作「OpenAI Tunnel 运行 Key」。

下面字段按本轮网页实测表单记录；如果平台表单变了，先核对标签，不要机械照抄。

1. 打开 [OpenAI Platform 运行 API Keys 页面](https://platform.openai.com/settings/organization/api-keys)，确认与 Tunnel 是同一个目标组织。不要去 Admin keys 创建管理员 Key 来运行连接。
2. 点 **Create new secret key**。
3. 按表单填写：

   | 字段 | 个人练习怎么选 |
   |---|---|
   | Owned by／所有者 | 自己（You） |
   | Name／名称 | `FolioHook 上手练习`，便于以后辨认 |
   | Project／项目 | 本组织内你有权限使用的项目；不要选他人的项目 |
   | Permissions／权限 | Restricted／受限；Tunnels 只选 **Read、Use**，无关权限不勾 |
   | Expiration／有效期（若提供） | 选择能覆盖练习期的期限，记下到期日 |

4. 确认后由你自己点创建／生成。复制展示的完整 **Secret Key**，立即填入下一步的本机输入框；不要发给 AI、截图或写进教程。
5. 保存好后关闭展示 Secret Key 的窗口，再让人帮你检查状态。

如果表单没有 Tunnels 权限，不要改成 All 来碰运气；先核对入口、组织和账号角色。Key 的受限勾选不能代替账号本身所需的组织权限。错过 Secret Key 展示或忘记它时也不要让 AI 读钥匙串取出。

### 9.5 填回 FolioHook

1. 进入「连接 AI 应用」→ **ChatGPT Secure MCP Tunnel · 真实连接**。
2. 在「OpenAI Tunnel 运行 Key」粘贴刚才生成的完整 **OpenAI API Secret Key**，点「保存运行 Key 到本机钥匙串」。不是填进全局设置的阿里云框。
3. 在「Tunnel ID」填 9.3 得到的 ID；不要把 Key 和 ID 对调。
4. 阅读“接受官方 Tunnel 客户端断线退避重连；应用不自动重启进程”。同意后勾选。
5. 点「保存连接设置」。

**成功标志：** Key 显示已配置，Tunnel ID 是你的目标 ID。保存成功只证明设置存下来了，还不代表网络已通。

### 9.6 启动并看状态

1. 点一次「启动真实 Tunnel」。不要点下方的「模拟启动」。
2. 等待自动检查：约每两秒一次，最多约 45 秒，就绪后停止自动检查。
3. 看到 **已连接（本地 Tunnel）** 后继续下一步。已经运行就不要重复启动。
4. 若一直“未就绪”，可以点保留的「检查真实连接」看当前情况；出现明确错误时先看权限、程序安装、ID、Key 有效期和网络，不连续重试。

**成功标志：** 本地状态就绪。还要完成网页创建和工具调用，不能到这里就认为网页已经可用了。

### 9.7 在 ChatGPT 网页添加连接

1. 回 ChatGPT，进入「插件／应用」的新增连接入口；名称可能随客户端语言变化。
2. 名称填 **FolioHook 上手练习**，描述填“只读查询我的练习文献库”。图标可以暂不上传。
3. 「连接」选择 **隧道**，不要把 `127.0.0.1` 管理页网址填到服务器 URL。
4. 从列表选你的 Tunnel。**下拉列表没有本次新建的 Tunnel，或只显示旧项目时：** 点「改用隧道 ID」，粘贴 9.3 得到的完整 `tunnel_…`，确认与 FolioHook 中保存的 ID 一致；不要选旧项目凑数，也不要在这里填 Secret Key。手填是官方支持的方式，不需要因此重建 Tunnel。若手填仍失败，再核对账号、目标工作区关联以及 Read + Use 权限；手填不会绕过权限。列表未显示的原因应单独核实，不能直接认定是缓存。[官方 Tunnel 连接说明](https://developers.openai.com/api/docs/guides/secure-mcp-tunnels)
5. 「身份验证」选择 **无身份验证**。这是当前 FolioHook MCP 的选项，不是取消 Tunnel 的运行 Key 保护。
6. 阅读自定义连接的风险与权限提示，确认信任这次连接后，再勾选确认并点「创建」。
7. 打开连接详情，查看是否发现 **8 个工具**，其中应有 `retrieval_status`、`search_documents`。

**成功标志：** 创建成功、工具已发现。若报 `does not implement OAuth`，检查是否误选 OAuth；若是泛化错误，返回 FolioHook 检查真实连接，不反复新建 Tunnel。[官方网页连接说明](https://developers.openai.com/plugins/deploy/connect-chatgpt)

### 9.8 新聊天里真正用一次

1. 新建 ChatGPT 聊天。
2. 在工具／插件菜单中选择 **FolioHook 上手练习**；不要误选旧项目的文献插件。
3. 发送：

> 只用本次选中的 FolioHook 连接，实际列出文献库，找到「我的上手练习」并选择当前激活版本。调用 search_documents，mode="bm25"，搜索 bluebridge842。告诉我备用裕度，给文件名和行号。不要用旧聊天代替工具，不用增强搜索；有同名库先问我。

**成功标志：** 展开网页的工具调用，能看到列库／版本与普通搜索，答案 **18%**，出处 **蓝桥补充.md**。

如果已完成第 5～7 步，并接受一次付费增强调用，再发送：

> 只用本次选中的 FolioHook，选择「我的上手练习」的当前激活版本。调用一次 search_documents，mode="enhanced"，查询“蓝桥练习中储能容量和调度延迟分别是多少”。不要重试，不要回退普通搜索。给答案、文件名、行号，以及工具实际返回的模型调用情况；有同名库先问我。

**成功标志：** **31 kWh、7 秒**，来源 **蓝桥电池.md**；工具记录确认是增强搜索，正常成功链有三个角色调用。看不到审计时如实记为未确认，不凭文字答案判定。

### 9.9 以后每天只需做什么

第一次配好后，不必再建 Tunnel、生成 Key、添加同名插件。以后启动 FolioHook，启动真实 Tunnel 并检查状态，然后在 ChatGPT 聊天里选用连接即可。Key 到期或权限变动时才处理对应设置。

电脑休眠／关机或本机服务停止，网页连接就不能假定仍可用。普通网页检索不调用阿里云模型，但摘录会交给 ChatGPT，不是全部数据处理都留在本机。

## 第 10 步：练一下移除文档（可选）

只在「我的上手练习」里做，别动原有库。

1. 进入「文档」，点「批量管理」。
2. 勾选 **蓝桥补充.md**，点「从新版本中移除」。
3. 确认名单后建立新版本，检查只剩 **蓝桥电池.md**。
4. 想让 AI 今后用这套资料，再把这个新版本设为当前。

**成功标志：** 新版本只剩 1 篇，旧版本仍有 2 篇。旧版本里的文件没有被擦掉，所以占用空间不会马上全部释放。

本轮先保留练习库，不需要永久删除。以后真要连历史版本和向量一起删除，再使用「库设置 → 永久删除文献库」；会再次要求输入库名确认，删除后不能撤销。

## 第 11 步：用完怎么关

1. 如果不再使用 ChatGPT 网页连接，在应用点「停止真实 Tunnel」，确认显示已停止。
2. 如果不再用本机 MCP，在 Codex 里停用**这条测试连接**。已建立会话可能需要重载或重启客户端后才真正断开。
3. 需要关闭管理服务时，先让维护者帮你确认它所在的终端，再按 `Ctrl+C`。不知道是哪个终端就先问，不要乱关其他项目。

关掉网页标签页，并不等于停止服务；停止服务也不会删除文献。

## 做完后怎么判断自己会用了

- 我能自己建库、导入，并找到 31 kWh、7 秒、18% 的原文。
- 我知道添加文件后要检查新版本，必要时设为当前。
- 我知道哪几个按钮会调用付费模型，不会把两家的 Key 填反。
- 我能分别在本机 Codex、ChatGPT 网页发消息，并确认真的用了文献库工具。
- 我知道用完后在哪里停止连接。

遇到卡点，只需要告诉维护者：**“我做到第几步、点了什么、现在出现什么。”** 不用自己猜原因，也不要发 Key。

更详细的安装、参数、数据位置和报错说明在[设置与使用参考](使用指南.md)。第一次练习不需要从头读完它。
