# Windows 测试安装说明

这是 **Windows 11、64 位 Intel/AMD 电脑**的未签名测试版。它不是正式发布版，云端构建成功也不代表已经在你的电脑上试装过。

## 可以先体验什么

创建资料库 → 导入 Markdown 或有文字层的 PDF → 保存版本 → 关键词搜索 → 在支持本地 MCP 的 AI 应用里查询，并查看出处。

这条本地流程不需要 OpenAI 或阿里云 Key，也不需要另装 Python、Node.js 或 Git。Windows 的真实增强搜索、系统凭据存储及网页 Tunnel 尚未作为这份候选包的交付能力；不要为此填写真实 Key。

## 安装和首次打开

1. 从本次明确提供的 GitHub 构建记录下载 `FolioHook-Windows-x64-unsigned-…`，解压后找到 `Setup.exe` 结尾的文件。
2. 双击安装。安装到当前用户，不需要把源码放到桌面。
3. 打开 **FolioHook**，创建一个“练习库”，导入你明确选择的练习文件。
4. 在“搜索”中选择关键词搜索，输入练习资料中的词，检查结果和出处。
5. 关闭窗口再打开，确认资料库和版本仍在。

未签名意味着 Windows 可能提示“未知发布者”或阻止运行。先核对文件来源；受单位管理的电脑请遵守设备策略。不要关闭杀毒软件或系统安全保护来安装。

## 连接本地 MCP

先正常打开一次 FolioHook，让它准备本机连接入口。随后进入“连接 AI 应用”，按当前页面显示的启动命令和参数，填入客户端的 **添加 MCP 服务器 → STDIO** 表单。不要复制开发者的电脑路径，也不要把命令填进网页服务器 URL。

本地 MCP 由客户端启动；关闭 FolioHook 窗口不应中断已经由客户端独立启动的 MCP。确认连接后，先让 AI 列出资料库，再选定练习库、版本和关键词查询。它只有读取工具，不能替你导入或删除资料。

## 更新与卸载

- 更新前关闭 FolioHook，并在 MCP 客户端断开这个连接。安装新测试包后，先打开一次 FolioHook，再重新连接 MCP。
- 用户资料存放在当前用户的 `%LOCALAPPDATA%\literature-evidence-mcp`，不在每次安装的版本目录中。
- 在 Windows“设置 → 应用”中卸载。卸载默认保留资料库；不要把卸载当作删除资料。
