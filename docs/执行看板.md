# 执行看板入口

本项目只有一份活看板，由管理任务维护，位于**主工作区**的 `local-artifacts/coordination/执行看板.md`。机器路径、内部任务 ID、实例、端口、共享配置负责人和实时验收进度只写在该本地文件，不提交 Git。

在主工作区可打开 [本机执行看板](../local-artifacts/coordination/执行看板.md)。这个相对链接在其他工作树或在线仓库可能不存在；不要据此新建副本。其他工作树使用管理任务交接的主工作区绝对入口，直接读取同一文件。

入口不明时可只读运行 `git rev-parse --git-common-dir` 查看共享 Git 元数据位置，并用 `git worktree list` 核对主工作区；不要把当前工作树误认成主工作区，也不要自动复制看板。本机文件被删除或换机后，应由管理任务根据实际状态重建并明确重新交接入口。

管理任务在分工、共享配置交接、验收节点或异常发生时更新看板。其他任务回报以下最小信息即可：负责范围、实际结果、证据路径、未解决项、下一步及所需用户操作。恢复后先读看板并核验相关实际状态；记录不能代替现场核验。

稳定规则见 [仓库协作约定](../AGENTS.md)，目标和验收条件见 [项目任务书](项目任务书.md)。
